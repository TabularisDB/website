# Still working on GTA VI day?

GTA VI is on the calendar. So is your 10 a.m. standup.

If you still have queries to run today, I made **Vice City for Tabularis**. It’s an unofficial theme with two palettes. **After Dark** gives your SQL editor neon pink, mint, and deep purple. **Daybreak** goes lighter with warm peach and rose. Both color the app, SQL syntax, and result grid.

![After Dark colors the SQL editor and the Vice City Garage result grid in purple, pink, and mint](/img/posts/vice-city-launch-day/after-dark.webp)

![Daybreak shows the same SQL query and garage inventory in peach, rose, and green](/img/posts/vice-city-launch-day/daybreak.webp)

## Take a lap while the query runs

I put a tiny getaway game above the console and table tabs in the optional preview. Hit **Play**, jump over barricades, pick up stars and shields, and try to keep the patrol car off your bumper.

*Recorded in a local Tabularis demo with a fictional SQLite garage inventory.*

**Space** jumps, **← / →** steer, **X** fires a pulse, and **Esc** gets you back to work. If you get caught, hit **Retry**.

## Get the theme

Grab [the free theme ZIP](https://github.com/TabularisDB/tabularis-vice-city-theme/releases/latest/download/theme-universal.zip). In Tabularis, open **Settings → Appearance → Import theme → Local package**, then pick **After Dark** or **Daybreak**. Set the SQL editor theme to **Same as App** for matching syntax colors.

For the panoramas and the game, follow the [optional Tabularis Web preview setup](https://github.com/TabularisDB/tabularis-vice-city-theme#optional-animated-web-preview).
